# PDF ภาษาไทย: แปลง / แก้ไข / Export (เว็บใช้ในเครื่อง)

แปลง PDF เป็น Word โดยซ่อมสระลอย วรรณยุกต์ และรหัสภาษาไทยที่เพี้ยนให้อัตโนมัติ ทำงานในเครื่องคุณเท่านั้น ไม่มีไฟล์ส่งออกไปอินเทอร์เน็ต

## วิธีเปิดใช้งาน

ต้องติดตั้ง [Docker Desktop](https://www.docker.com/products/docker-desktop/) และเปิดโปรแกรมไว้ก่อน

```bash
cd ~/Desktop/"test PDF To word"
docker compose up -d --build
```

ครั้งแรกจะใช้เวลาสร้างประมาณ 5–10 นาที (ดาวน์โหลด LibreOffice ประมาณ 400 MB) จากนั้นเปิดเบราว์เซอร์ไปที่ **http://localhost:8080**

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `docker compose up -d` | เปิดเว็บ (ถ้าปิดไว้) |
| `docker compose down` | ปิดเว็บ |
| `docker compose logs -f` | ดู log เวลามีปัญหา |
| `docker compose up -d --build` | สร้างใหม่หลังแก้โค้ด |

ตั้งค่าไว้ให้เว็บเปิดเองทุกครั้งที่เปิด Docker Desktop (`restart: unless-stopped`)

## หน้าเว็บมี 2 หน้า

- **http://localhost:8080** – แปลง PDF → Word (ทีละหลายไฟล์)
- **http://localhost:8080/editor** – แก้ไข PDF และ Export

## แก้ไข PDF (หน้า /editor)

เปิดได้ทั้ง PDF, Word, Excel, PowerPoint และรูปภาพ (ไฟล์ที่ไม่ใช่ PDF จะแปลงเป็น PDF ให้ก่อน)

| เครื่องมือ | ทำอะไรได้ |
|---|---|
| แก้ข้อความ | คลิกที่ข้อความเดิมแล้วพิมพ์แก้ได้เลย ขนาดและความหนาเทียบกับของเดิมให้อัตโนมัติ |
| เพิ่มข้อความ | คลิกตรงไหนก็พิมพ์ได้ ปรับขนาด สี ตัวหนา ตัวเอียง ขีดเส้นใต้ |
| รูปภาพ / ลายเซ็น | ใส่รูป หรือเซ็นชื่อด้วยเมาส์/ทัชแพด แล้วลากย้ายและปรับขนาดได้ |
| ไฮไลต์ / ปากกา / กรอบ / เส้น | ลากบนหน้าเอกสาร |
| ลบ/ปิดทับ | ลากคลุม ข้อความใต้กรอบจะถูกลบออกจากไฟล์จริง ไม่ใช่แค่ปิดทับ |
| จัดการหน้า | แถบซ้าย: ลากเรียงหน้าใหม่, หมุน, ทำสำเนา, ลบ, เพิ่มหน้าว่าง |
| รวมไฟล์ | เพิ่ม PDF / Word / Excel / รูป ต่อท้าย |
| ลายน้ำ / เลขหน้า | ใส่ทุกหน้า เลือกเลขไทยได้ |
| ย้อนกลับ / ทำซ้ำ | Ctrl+Z / Ctrl+Y ย้อนได้ทุกขั้น (บันทึก Ctrl+S) |

**Export:** PDF, Word (.docx), Excel (.xlsx ดึงตาราง), รูป PNG/JPG, ข้อความ .txt
ใส่เลขหน้า เช่น `1-3,5` เพื่อแยกเฉพาะบางหน้าออกมาได้

**การแก้ข้อความเดิม:** คลิกบรรทัดแล้วพิมพ์ ระบบลบตัวอักษรเดิมออกจากไฟล์จริง (ไม่ใช่เอาสีขาวทับ)
แล้วเขียนข้อความใหม่ลงบน **เส้นฐานเดิมพอดี** ด้วยฟอนต์ **Sarabun TH Compat** ที่ขนาด น้ำหนักเส้น และระยะเท่า TH SarabunIT๙
ทดสอบด้วยการพิมพ์ทับทุกบรรทัดด้วยข้อความเดิม: ตำแหน่ง ขนาด ตัวหนา/ธรรมดา ตรงกับต้นฉบับ และข้อความที่ค้นหาได้ถูกทุกบรรทัด

- ระหว่างแก้ หน้าเว็บแสดงภาพหน้าที่ลบบรรทัดเดิมออกจริง (จากเซิร์ฟเวอร์) จึงไม่มีรอยสระ/วรรณยุกต์ซ้อน
- บรรทัดที่มีทั้งตัวหนาและตัวธรรมดา (เช่น "**หน่วยงานที่ให้บริการ :** สำนักงาน...") คงรูปแบบเดิมทุกส่วน
- เลือกคำแล้วกด B / I / U / สี เพื่อเปลี่ยนเฉพาะคำนั้นได้ (ไม่เลือก = ทั้งบรรทัด)
- เอกสารฟอนต์ไม่มีหัว (Tahoma, Leelawadee) ใช้ Noto Sans Thai ให้อัตโนมัติ

**ภาษาไทยใน PDF ที่แก้แล้วไม่เพี้ยน:** จัดรูปสระ/วรรณยุกต์ด้วย HarfBuzz (เครื่องมือเดียวกับที่เบราว์เซอร์และ Word ใช้)
วาดเป็นรูปตัวอักษร และเก็บตัวหนังสือที่ถูกต้องไว้อีกชั้น จึงค้นหา (Ctrl+F) และ copy ภาษาไทยได้ถูกทุกตัว
ไม่เกิดปัญหา "การ" กลายเป็น "กำร" แบบที่ Word + Cordia New ทำ

## ฟอนต์ไทย

- **Sarabun TH Compat** = ฟอนต์ Sarabun (Google, ลิขสิทธิ์ OFL ใช้ฟรี) ที่ปรับขนาดให้เท่า TH Sarabun New / TH SarabunIT๙
  (วัดความกว้างจากบรรทัดจริงใน PDF ต่างกันไม่ถึง 0.3%) ความหนาเส้นเลือกจากการวัดก้านตัวอักษรเทียบต้นฉบับ 81 บรรทัด:
  ตัวธรรมดาใช้น้ำหนัก ExtraLight (ก้าน 0.96 เท่าของต้นฉบับ) ตัวหนาใช้ Medium (1.04 เท่า)
  บรรทัดที่แก้จึงหนาเท่าบรรทัดเดิมรอบข้าง (รุ่นก่อนใช้ Light ซึ่งหนากว่าต้นฉบับ 17% เห็นเป็นตัวหนาๆ)
- ตอนแปลงเป็น Word ระบบ **ฝังฟอนต์ลงในไฟล์ .docx** เปิดเครื่องไหนก็แสดงถูก ไม่ขึ้น ⚠ ใน Word และไม่ล้นตาราง
- ถ้าต้องการใช้ TH Sarabun New ตัวจริง: วางไฟล์ฟอนต์ (.ttf) ไว้ในโฟลเดอร์ `my-fonts` แล้ว `docker compose restart`
  จากนั้นเลือก "TH Sarabun New" ตอนแปลง ระบบจะฝังฟอนต์จริงให้

## การแปลง PDF → Word: สิ่งที่ซ่อมให้

- **เส้นตารางหาย:** pdf2docx เขียนค่าที่ Word อ่านไม่ได้ (ขนาดเส้นเป็นทศนิยม, สี "#000000", สีพื้นไม่มี w:val) Word จึงทิ้งเส้นขอบ/สีพื้น
  ระบบแก้ทุกค่าให้ตรงมาตรฐาน (ไฟล์ 44588: แก้ 881 จุด)
- **โครงสร้างไฟล์ผิดมาตรฐาน:** pdf2docx เรียงเส้นขอบช่องเป็น ซ้าย-บน-ขวา-ล่าง (มาตรฐานคือ บน-ซ้าย-ล่าง-ขวา), ใส่ระยะเยื้องตารางผิดที่,
  ใช้ชื่อ w:start/w:end, ใส่ระยะขอบช่องซ้ำ -> Word ข้ามค่าพวกนี้เงียบๆ (เส้นขอบหาย) ระบบจัดเรียงใหม่ทั้งไฟล์
  ตรวจกับ XML Schema มาตรฐาน OOXML แล้ว: ไฟล์ 44588 จาก 257 จุดผิด เหลือ 0 (`tests/validate_docx.py`)
- **ตารางเยื้องซ้าย 5.4pt:** ไฟล์เป็นโหมด Word 2010 ซึ่งดึงตารางออกซ้ายเท่าระยะขอบช่อง -> ตั้งค่าให้ตารางอยู่ตำแหน่งเดียวกับ PDF (คลาดไม่ถึง 0.3pt)
- **เส้นคู่ (double):** pdf2docx รวมเส้นขนาน 2 เส้นเป็นเส้นเดียว -> ตรวจจาก PDF แล้วตั้งขอบช่องเป็นเส้นคู่ของ Word
- **เส้นที่ไม่ใช่ตาราง** (เส้นประในแบบฟอร์ม, เส้นคั่นใต้หัวเรื่อง) ที่ pdf2docx ทิ้ง -> ใส่กลับเป็นเส้นตรง ยึดกับบรรทัดข้อความ (ขยับตามข้อความ)
- **ตกหน้า/เพิ่มหน้า:** ไม่สร้างหัว-ท้ายกระดาษว่าง (เดิมดันเนื้อหาลง 12pt) จำนวนหน้าเท่าต้นฉบับ
- **คำตกบรรทัด:** ตัดบรรทัดตรงกับ PDF ทุกบรรทัด และไม่ใช้ระยะเยื้องขวาที่ทำให้คำสุดท้ายตก
- ตัวหนาภาษาไทย (bCs), ขนาดตัวอักษรไทย (szCs), เลขไทยของ TH SarabunIT๙, ความกว้างคอลัมน์ตาราง

ผลทดสอบ 44588.pdf (แปลงเป็น Word แล้วแปลงกลับเป็น PDF เทียบกับต้นฉบับ): 7 หน้า -> 7 หน้า, เส้นตาราง 100%,
ตำแหน่งตารางคลาด 0.1pt, คำครบ 1,677/1,677, ผิดมาตรฐาน OOXML 0 จุด
ชุดทดสอบเพิ่ม (ตารางมีเส้น+พื้นสี+ผสานช่อง, แบบฟอร์มเส้นประ+กรอบเส้นคู่, ตารางกรอบนอกเส้นคู่, ตารางยาวข้ามหน้า,
รายการ, ฟอนต์ Tahoma): เส้นตาราง 100%, คำครบทุกไฟล์, ผิดมาตรฐาน 0 จุด

```bash
docker compose exec pdf2word python tests/eval_convert.py ไฟล์.pdf
docker compose exec pdf2word python tests/validate_docx.py ไฟล์.docx
```

## โหมดการแปลง

| โหมด | เหมาะกับ | ความแม่นยำ |
|---|---|---|
| **อัตโนมัติ** (แนะนำ) | ทุกไฟล์ โปรแกรมจะตรวจไฟล์แล้วเลือกระหว่าง "ดึงข้อความ" กับ "OCR" ให้เอง | — |
| **ดึงข้อความ** | PDF ที่สร้างจาก Word หรือโปรแกรมอื่นโดยตรง เก็บตารางและรูปแบบหน้าไว้ | 99–100% |
| **OCR** | ไฟล์สแกน หรือไฟล์ที่ข้อความข้างในเสีย (การจัดหน้าจะหายไป ตรวจคำที่ไฮไลต์สีเหลือง) | ~97% (ไฟล์ชัด) |
| **รูปภาพ** | ต้องการให้หน้าตาเหมือนต้นฉบับทุกอย่าง | 100% (แต่แก้ไขข้อความไม่ได้) |

## สิ่งที่ซ่อมให้อัตโนมัติ

- สระและวรรณยุกต์ที่เป็นรหัส PUA (U+F700–F71A) เช่น ที่ ปู่ ญี่ปุ่น
- วรรณยุกต์ที่มาก่อนสระ (ท + ่ + ี → ที่)
- สระอำที่แตกเป็น ํ + า
- สระหรือวรรณยุกต์ซ้ำ (ทั้ั้ง → ทั้ง)
- ข้อความไทยรหัสเก่า TIS-620 ที่ขึ้นเป็นภาษาต่างดาว (¡ÒÃ»ÃÐªØÁ → การประชุม)
- ตั้งฟอนต์และขนาดตัวอักษรภาษาไทยใน Word ให้ถูกต้อง (Word แยกฟอนต์ภาษาไทยไว้ต่างหาก ถ้าไม่ตั้งจะได้ตัวเล็กหรือเพี้ยน)

## OCR + แก้คำผิดด้วยพจนานุกรม

โหมด OCR ใช้ Tesseract อ่านภาษาไทย แล้วใช้พจนานุกรมภาษาไทย (PyThaiNLP) แก้คำที่อ่านผิด เช่น
"ชัวคราว" → "ชั่วคราว", "หลกเกณฑ์" → "หลักเกณฑ์", "บุคค ลวิกลจริต" → "บุคคลวิกลจริต"

- แก้เฉพาะสระ วรรณยุกต์ และช่องว่างแทรกกลางคำ ไม่เปลี่ยนพยัญชนะ
- แก้เฉพาะคำที่ไม่มีในพจนานุกรม และต้องแก้แล้วได้คำที่ใช้บ่อย คำที่ถูกอยู่แล้วจึงไม่ถูกแตะ
- **คำที่ถูกแก้จะไฮไลต์สีเหลืองใน Word** ให้ตรวจทาน
- ปิดได้ที่ช่องติ๊กในหน้าเว็บ

ผลทดสอบกับข้อความราชการจริง 4 ฟอนต์: PDF คมชัด 96.3% → 97.7%, ไฟล์สแกน 96.1% → 97.4%

## ชุดทดสอบภาษาไทยครบทุกตัว

`tests/test_thai_all.py` ทดสอบตัวซ่อมกับพยัญชนะ 44 ตัว + อักษรควบ x ทุกรูปสระ x ทุกวรรณยุกต์ (18,528 คำ)

```bash
docker compose exec pdf2word python tests/test_thai_all.py
```

## ปัญหาที่พบบ่อย

- **เปิด Word แล้วขึ้น ⚠ ที่ชื่อฟอนต์ หรือข้อความล้นตาราง**: เลือกฟอนต์ "Sarabun TH Compat" ตอนแปลง (ฝังในไฟล์ให้)
  ถ้าเลือกฟอนต์อื่น เครื่องที่เปิดต้องมีฟอนต์นั้น หรือวางไฟล์ฟอนต์ไว้ใน `my-fonts` ให้ระบบฝัง
- **หลังอัปเดตแล้วหน้าแก้ไขยังดูเหมือนเดิม**: กด Cmd+Shift+R (Windows: Ctrl+F5) ให้เบราว์เซอร์โหลดฟอนต์/หน้าใหม่
- **OCR อ่านผิดบางตัว** (เช่น ด/ค หรือ บ/ป): เป็นข้อจำกัดของ OCR ไฟล์ยิ่งคมชัดยิ่งแม่น ควรตรวจทานทุกครั้ง
- **พอร์ต 8080 ถูกใช้อยู่แล้ว**: แก้ใน `docker-compose.yml` เป็น `"127.0.0.1:8090:8080"` แล้วเปิด http://localhost:8090

## ไฟล์ในโปรเจกต์

- `converter.py`: ตัวแปลง PDF → Word และตัวซ่อมภาษาไทย
- `editor.py`: ระบบแก้ไข PDF + Export
- `thai_pdf_text.py`: เขียนภาษาไทยลง PDF (HarfBuzz) ให้ถูกทั้งตาเห็นและค้นหา
- `docx_fix.py`: แก้ค่า/ลำดับใน .docx ให้ตรงมาตรฐานที่ Word ต้องการ + ตำแหน่งตาราง + ฝังฟอนต์
- `tests/eval_convert.py`: วัดคุณภาพการแปลงเทียบต้นฉบับ (`python tests/eval_convert.py ไฟล์.pdf`)
- `tests/validate_docx.py`: ตรวจไฟล์ .docx กับ XML Schema มาตรฐาน (ครั้งแรกดาวน์โหลด schema ~400 KB)
- `tests/make_samples.py`: สร้างเอกสารทดสอบภาษาไทยหลายแบบ
- `tools/build_fonts.py`: สร้างฟอนต์ Sarabun TH Compat
- `templates/editor.html`: หน้าแก้ไข PDF
- `static/fonts/`: ฟอนต์ไทย Sarabun TH Compat / Noto Sans Thai (ลิขสิทธิ์ OFL ใช้ฟรี), `fonts/thai-aliases.conf`: จับคู่ชื่อฟอนต์
- `my-fonts/`: วางฟอนต์ของคุณเอง
- `thai_ocr_fix.py`: แก้คำผิดจาก OCR ด้วยพจนานุกรม
- `tests/`: ชุดทดสอบภาษาไทยครบทุกตัว
- `app.py`: เว็บเซิร์ฟเวอร์ (Flask)
- `templates/index.html`: หน้าเว็บ
- `Dockerfile`, `docker-compose.yml`: ตั้งค่า Docker
