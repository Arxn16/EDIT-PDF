# PDF ภาษาไทย: แปลง / แก้ไข / Export (เว็บใช้ในเครื่อง)

แปลง PDF เป็น Word โดยซ่อมสระลอย วรรณยุกต์ และรหัสภาษาไทยที่เพี้ยนให้อัตโนมัติ ทำงานในเครื่องคุณเท่านั้น ไม่มีไฟล์ส่งออกไปอินเทอร์เน็ต

## วิธีเปิดใช้งาน

ต้องติดตั้ง [Docker Desktop](https://www.docker.com/products/docker-desktop/) และเปิดโปรแกรมไว้ก่อน

```bash
cd ~/Desktop/"test PDF To word"
docker compose up -d --build
```

ครั้งแรกจะใช้เวลาสร้างประมาณ 5–10 นาที (ดาวน์โหลด LibreOffice ประมาณ 400 MB) จากนั้นเปิดเบราว์เซอร์ไปที่ **http://localhost:8080**

| คำสั่ง | ใช้ทำอะไร |
|---|---|
| `docker compose up -d` | เปิดเว็บ (ถ้าปิดไว้) |
| `docker compose down` | ปิดเว็บ |
| `docker compose logs -f` | ดู log เวลามีปัญหา |
| `docker compose up -d --build` | สร้างใหม่หลังแก้โค้ด |

ตั้งค่าไว้ให้เว็บเปิดเองทุกครั้งที่เปิด Docker Desktop (`restart: unless-stopped`)

## หน้าเว็บมี 2 หน้า

- **http://localhost:8080** – แปลง PDF → Word (ทีละหลายไฟล์)
- **http://localhost:8080/editor** – แก้ไข PDF และ Export

## แก้ไข PDF (หน้า /editor)

เปิดได้ทั้ง PDF, Word, Excel, PowerPoint และรูปภาพ (ไฟล์ที่ไม่ใช่ PDF จะแปลงเป็น PDF ให้ก่อน)

| เครื่องมือ | ทำอะไรได้ |
|---|---|
| แก้ข้อความ | คลิกที่ข้อความเดิมแล้วพิมพ์แก้ได้เลย ขนาดและความหนาเทียบกับของเดิมให้อัตโนมัติ |
| เพิ่มข้อความ | คลิกตรงไหนก็พิมพ์ได้ ปรับขนาด สี ตัวหนา ตัวเอียง ขีดเส้นใต้ |
| รูปภาพ / ลายเซ็น | ใส่รูป หรือเซ็นชื่อด้วยเมาส์/ทัชแพด แล้วลากย้ายและปรับขนาดได้ |
| ไฮไลต์ / ปากกา / กรอบ / เส้น | ลากบนหน้าเอกสาร |
| ลบ/ปิดทับ | ลากคลุม ข้อความใต้กรอบจะถูกลบออกจากไฟล์จริง ไม่ใช่แค่ปิดทับ |
| จัดการหน้า | แถบซ้าย: ลากเรียงหน้าใหม่, หมุน, ทำสำเนา, ลบ, เพิ่มหน้าว่าง |
| รวมไฟล์ | เพิ่ม PDF / Word / Excel / รูป ต่อท้าย |
| ลายน้ำ / เลขหน้า | ใส่ทุกหน้า เลือกเลขไทยได้ |
| ย้อนกลับ / ทำซ้ำ | Ctrl+Z / Ctrl+Y ย้อนได้ทุกขั้น (บันทึก Ctrl+S) |

**Export:** PDF, Word (.docx), Excel (.xlsx ดึงตาราง), รูป PNG/JPG, ข้อความ .txt
ใส่เลขหน้า เช่น `1-3,5` เพื่อแยกเฉพาะบางหน้าออกมาได้

**ภาษาไทยใน PDF ที่แก้แล้วไม่เพี้ยน:** ระบบวาดตัวอักษรให้ตาเห็นถูกต้อง และเก็บตัวหนังสือที่ถูกต้องไว้ในไฟล์อีกชั้น
จึงค้นหา (Ctrl+F) และ copy ภาษาไทยได้ถูกทุกตัว ไม่เกิดปัญหา "การ" กลายเป็น "กำร" แบบที่ Word + Cordia New ทำ

ข้อจำกัด: ข้อความที่แก้หรือเพิ่มจะใช้ฟอนต์ Noto Sans Thai (ไม่ใช่ฟอนต์เดิมของไฟล์) และบรรทัดที่มีทั้งตัวหนาและตัวธรรมดาปนกัน
เมื่อแก้แล้วจะกลายเป็นแบบเดียวทั้งบรรทัด (กดปุ่ม B เพื่อสลับ)

## ฟอนต์ไทย

ใน Docker มีฟอนต์ **Sarabun TH Compat** ที่ขนาดเท่ากับ TH Sarabun New / TH SarabunIT๙ / Cordia New / Angsana New
ใช้แทนอัตโนมัติเวลาแปลง Word/Excel เป็น PDF จะได้ไม่ล้นตารางหรือตกหน้า
ถ้ามีไฟล์ฟอนต์จริง (เช่น THSarabunNew.ttf) วางไว้ในโฟลเดอร์ `my-fonts` แล้วสั่ง `docker compose restart` ระบบจะใช้ฟอนต์จริงก่อน

## โหมดการแปลง

| โหมด | เหมาะกับ | ความแม่นยำ |
|---|---|---|
| **อัตโนมัติ** (แนะนำ) | ทุกไฟล์ โปรแกรมจะตรวจไฟล์แล้วเลือกระหว่าง "ดึงข้อความ" กับ "OCR" ให้เอง | — |
| **ดึงข้อความ** | PDF ที่สร้างจาก Word หรือโปรแกรมอื่นโดยตรง เก็บตารางและรูปแบบหน้าไว้ | 99–100% |
| **OCR** | ไฟล์สแกน หรือไฟล์ที่ข้อความข้างในเสีย (การจัดหน้าจะหายไป ตรวจคำที่ไฮไลต์สีเหลือง) | ~97% (ไฟล์ชัด) |
| **รูปภาพ** | ต้องการให้หน้าตาเหมือนต้นฉบับทุกอย่าง | 100% (แต่แก้ไขข้อความไม่ได้) |

## สิ่งที่ซ่อมให้อัตโนมัติ

- สระและวรรณยุกต์ที่เป็นรหัส PUA (U+F700–F71A) เช่น ที่ ปู่ ญี่ปุ่น
- วรรณยุกต์ที่มาก่อนสระ (ท + ่ + ี → ที่)
- สระอำที่แตกเป็น ํ + า
- สระหรือวรรณยุกต์ซ้ำ (ทั้ั้ง → ทั้ง)
- ข้อความไทยรหัสเก่า TIS-620 ที่ขึ้นเป็นภาษาต่างดาว (¡ÒÃ»ÃÐªØÁ → การประชุม)
- ตั้งฟอนต์และขนาดตัวอักษรภาษาไทยใน Word ให้ถูกต้อง (Word แยกฟอนต์ภาษาไทยไว้ต่างหาก ถ้าไม่ตั้งจะได้ตัวเล็กหรือเพี้ยน)

## OCR + แก้คำผิดด้วยพจนานุกรม

โหมด OCR ใช้ Tesseract อ่านภาษาไทย แล้วใช้พจนานุกรมภาษาไทย (PyThaiNLP) แก้คำที่อ่านผิด เช่น
"ชัวคราว" → "ชั่วคราว", "หลกเกณฑ์" → "หลักเกณฑ์", "บุคค ลวิกลจริต" → "บุคคลวิกลจริต"

- แก้เฉพาะสระ วรรณยุกต์ และช่องว่างแทรกกลางคำ ไม่เปลี่ยนพยัญชนะ
- แก้เฉพาะคำที่ไม่มีในพจนานุกรม และต้องแก้แล้วได้คำที่ใช้บ่อย คำที่ถูกอยู่แล้วจึงไม่ถูกแตะ
- **คำที่ถูกแก้จะไฮไลต์สีเหลืองใน Word** ให้ตรวจทาน
- ปิดได้ที่ช่องติ๊กในหน้าเว็บ

ผลทดสอบกับข้อความราชการจริง 4 ฟอนต์: PDF คมชัด 96.3% → 97.7%, ไฟล์สแกน 96.1% → 97.4%

## ชุดทดสอบภาษาไทยครบทุกตัว

`tests/test_thai_all.py` ทดสอบตัวซ่อมกับพยัญชนะ 44 ตัว + อักษรควบ x ทุกรูปสระ x ทุกวรรณยุกต์ (18,528 คำ)
กับความเสียหาย 9 แบบ (PUA, ช่องว่างแทรก, วรรณยุกต์สลับ, สระอำแตก, นิคหิตหาย, สระซ้ำ ฯลฯ) และรหัสไทยเก่า TIS-620

```bash
docker compose exec pdf2word python tests/test_thai_all.py
```

## ปัญหาที่พบบ่อย

- **เปิด Word แล้วสระซ้อนกันหรือฟอนต์ไม่สวย**: เครื่องไม่มีฟอนต์ที่เลือกไว้ ให้ติดตั้ง TH Sarabun New หรือเลือกฟอนต์ Tahoma ตอนแปลง
- **OCR อ่านผิดบางตัว** (เช่น ด/ค หรือ บ/ป): เป็นข้อจำกัดของ OCR ไฟล์ยิ่งคมชัดยิ่งแม่น ควรตรวจทานทุกครั้ง
- **พอร์ต 8080 ถูกใช้อยู่แล้ว**: แก้ใน `docker-compose.yml` เป็น `"127.0.0.1:8090:8080"` แล้วเปิด http://localhost:8090

## ไฟล์ในโปรเจกต์

- `converter.py`: ตัวแปลง PDF → Word และตัวซ่อมภาษาไทย
- `editor.py`: ระบบแก้ไข PDF + Export
- `thai_pdf_text.py`: เขียนภาษาไทยลง PDF ให้ถูกทั้งตาเห็นและค้นหา
- `templates/editor.html`: หน้าแก้ไข PDF
- `fonts/`, `static/fonts/`: ฟอนต์ไทย (ลิขสิทธิ์ OFL ใช้ฟรี)
- `my-fonts/`: วางฟอนต์ของคุณเอง
- `thai_ocr_fix.py`: แก้คำผิดจาก OCR ด้วยพจนานุกรม
- `tests/`: ชุดทดสอบภาษาไทยครบทุกตัว
- `app.py`: เว็บเซิร์ฟเวอร์ (Flask)
- `templates/index.html`: หน้าเว็บ
- `Dockerfile`, `docker-compose.yml`: ตั้งค่า Docker
